DESI DASTARKHAWAN — GITHUB PAGES WEBSITE

Included pages:
- index.html   (Home)
- menu.html    (Menu)
- about.html   (About Us)
- gallery.html (Gallery)

All pages use the shared style.css and script.js files.
Images are stored in the images/ folder.

HOW TO USE:
1. Extract this ZIP file.
2. Open the extracted desi_dastarkhawan_site folder.
3. Open index.html in your browser to preview the website.
4. Put all files and the images folder in the root of your GitHub repository.
   Keep the folder structure unchanged.
5. Commit and push your files using GitHub Desktop.
6. On GitHub, open your repository -> Settings -> Pages.
7. Under Build and deployment, choose "Deploy from a branch".
8. Select branch "main" and folder "/ (root)", then Save.
9. Wait for GitHub Pages to publish. Your site URL will appear in Settings -> Pages.
